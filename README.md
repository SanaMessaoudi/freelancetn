# FreelanceTN

## Project Overview

FreelanceTN is a web platform designed to connect freelancers with clients in Tunisia.

## Problem Statement

Finding reliable freelancers and managing freelance projects can be difficult. Clients may struggle to find people with the right skills, while freelancers may have difficulty finding projects and organizing their work.

FreelanceTN aims to simplify this process by bringing clients and freelancers together in one platform.

## Main Features

- User registration and authentication
- Freelancer profiles and skills
- Project publication
- Freelance proposals
- Project milestones and progress tracking
- Notifications and project management

## Technologies

- Frontend: Angular
- Backend: Spring Boot
- Database: PostgreSQL
- Containerization: Docker

## Project Goal

Build a reliable, secure, and user-friendly application while practicing software engineering, problem-solving, planning, and technical communication.
