# FreelanceTN — User Stories

## Epic 1: Authentication

**US01 — Freelancer Registration**

As a freelancer, I want to create an account so that I can access the platform and find job opportunities.

**US02 — Company Registration**

As a company, I want to create an account so that I can publish job offers and find Tunisian freelancers.

**US03 — Login**

As a user, I want to log in so that I can access my personal account.

**US04 — Logout**

As a user, I want to log out so that my account remains secure.

## Epic 2: Freelancer Management

**US05 — Create Profile**

As a freelancer, I want to create my professional profile so that international companies can discover my skills.

**US06 — Upload CV**

As a freelancer, I want to upload my CV so that companies can learn about my experience.

## Epic 3: Job Management

**US07 — Publish Job**

As a company, I want to publish a job offer so that freelancers can apply.

**US08 — Search Jobs**

As a freelancer, I want to search and filter job offers so that I can find opportunities matching my skills.

## Epic 4: Applications

**US09 — Apply for a Job**

As a freelancer, I want to apply for a job so that I can be considered by the company.

**US10 — Review Applications**

As a company, I want to review applications so that I can select the right freelancer.
